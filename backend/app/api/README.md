# `app/api/` — HTTP Route Handlers

All FastAPI routers. Each module (or package) provides one router mounted in `app/main.py`.

## Files

### `auth.py` — `/auth`

| Method | Path       | Auth   | Description                                                                 |
| ------ | ---------- | ------ | --------------------------------------------------------------------------- |
| GET    | `/auth/me` | Bearer | Returns `UserInfo` for the authenticated user (id, display_name, is_admin). |

### `app_config.py` — `/config`

| Method | Path      | Auth | Description                                                                                                                                                                     |

### `devices/` — `/devices`

A package; the URL paths are unchanged. `__init__.py` merges the routers of the modules below into `devices.router`.

| Module          | Responsibility                                                                                                                                                                     |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `common.py`     | Shared helpers: `make_router`, `get_services`, `get_entry`, `verify_lock_ownership`, `get_locked_online_driver`, `lock_info_dict`, `publish_lock_event`, `reconcile_expired_lock`. |
| `listing.py`    | `GET /devices`, `GET /devices/{id}`.                                                                                                                                               |
| `lock.py`       | `lock`, `unlock` (incl. soft), `heartbeat`.                                                                                                                                        |
| `commands.py`   | `run`, `stop`, `single`, `force-trigger`, `autoscale`.                                                                                                                             |
| `acquire.py`    | `preview`, `acquire`, `acquire/cancel`, `channels/{ch}/data`.                                                                                                                      |
| `frames.py`     | Blocking `read_frame()` (reads all channels, applies progress/cancel hooks) and `waveform_payload()`.                                                                              |
| `progress.py`   | `ProgressPublisher`: throttled (<= 5/s), thread-safe `progress` SSE events.                                                                                                        |
| `settings.py`   | `settings`, `memory-depth`, channel / timebase / trigger setters.                                                                                                                  |
| `screenshot.py` | `GET`/`POST screenshot`.                                                                                                                                                           |
| `probe.py`      | `GET probe`.                                                                                                                                                                       |

| Method | Path                                        | Auth   | Lock needed | Description                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------ | ------------------------------------------- | ------ | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/devices`                                  | Bearer | —           | List all devices with state, lock info, `online_since_utc`, and `uptime_minutes`. A `LOCKED` device whose lock expired in Redis is reset to `ONLINE`.                                                                                                                                                                                                                                                                                               |
| GET    | `/devices/{device_id}`                      | Bearer | —           | Detailed device info: state, label, `capabilities` (derived from the driver: `run`, `stop`, `acquire`, `preview`, `screenshot` + `single`, `force_trigger`, `autoscale`, `cancel_acquire` when supported; `[]` when offline), `channel_count`, `online_since_utc`, `uptime_minutes`. | POST   | `/devices/{device_id}/autoscale`            | Bearer | Own lock    | Scope Auto-Setup; returns after the scope settled (capability `autoscale`). | POST   | `/devices/{device_id}/preview`              | Bearer | Own lock    | Read one live frame of `?channels=` (default: enabled channels) **without storing anything**. Returns `{channels, waveforms[{artifact_id:null,…}], timebase, trigger}`.                                                                                                                                                                                                                                                                             |
| POST   | `/devices/{device_id}/acquire`              | Bearer | Own lock    | Capture a stored acquisition. `?channels=` limits channels, `?max_samples=true` reads the full memory (timeout 120 s, publishes `progress` SSE events), `?run_id=` groups a series, `?include_data=true` adds `waveforms` (with real `artifact_id`s). Optional commands (`single`, `force-trigger`, `autoscale`) check `capability in driver.capabilities` and answer 400 `not_supported` otherwise. A full-memory read can be cancelled only while it is running; `acquire/cancel` returns `{cancelled:false}` when nothing is in flight.

### `sessions/` — `/sessions`

A package; URL paths unchanged. Every `/sessions/{session_id}/…` route depends on `access.require_session_access`: if the session has a recorded owner who is neither the caller nor the caller is an admin → 403 `forbidden`. Legacy sessions without an owner and unknown sessions keep their old behaviour.

| -------------- | ---------------------------------------------------------------------------------------------------------- |
| `access.py`    | `require_session_access` dependency (owner / admin check).                                                 |

| `commit.py`    | `POST …/commit`, openBIS deep-link builder, dropbox variant.                                               |
| `download.py`  | `GET …/download` (ZIP) and `GET …/export.h5` (HDF5), built on the server, temp file removed after sending. |

### `openbis_structure.py` — `/openbis/structure`

Live OpenBIS hierarchy queries (lazily loaded, 5-minute TTL cache per token+params). All require Bearer auth; the user's token is forwarded to pybis.

| Method | Path                             | Query params              | Response items                       |
| ------ | -------------------------------- | ------------------------- | ------------------------------------ |
| GET    | `/openbis/structure/projects`    | `?space=` (optional)      | `[{code, display_name, semester}]`   |
| GET    | `/openbis/structure/collections` | `?project=`, `?space=`    | `[{code, display_name, identifier}]` |
| GET    | `/openbis/structure/objects`     | `?collection=`, `?space=` | `[{code, type, identifier}]`         |

`display_name` for projects is derived from the code (e.g. `DI_X_LOLOVIC` → `Dienstag — LOLOVIC`). `identifier` for collections is the full path `/SPACE/PROJECT/COLLECTION`, suitable for use as `experiment_id` in the commit endpoint. `identifier` for objects is the full OpenBIS sample path, suitable for use as `object_id`. The default space is `settings.OPENBIS_SPACE` (`GP_2025_WISE`).

### `events.py` — `/devices/events`

Server-Sent Events channel for real-time device, lock and acquisition-progress push. The events router is included **before** the devices router in `app/main.py` so `GET /devices/events` is not swallowed by `GET /devices/{device_id}`.

| Method | Path              | Auth   | Description                                                                                                            |
| ------ | ----------------- | ------ | ---------------------------------------------------------------------------------------------------------------------- |
| GET    | `/devices/events` | Bearer | SSE stream. Sends `data: {type, ...}\n\n` on device state transitions and lock changes. Keepalive `: ping` every 20 s. |

Event types:

- `device_state` — `{type, device_id, state, last_error}` — emitted when a device transitions state.
- `lock` — `{type, device_id, owner_user, session_id|null}` — emitted on lock acquire/release and when an expired lock is detected.
- `progress` — `{type, device_id, session_id, job:"acquire", done (0..1 across all channels), detail}` — emitted (<= 5/s) while a full-memory (`max_samples=true`) acquire reads, e.g. `detail: "CH2: 1,2 / 6 MPkt"`.

The `EventBus` (in-process fan-out queue) is attached to `app.state.event_bus` at startup. `InstrumentManager`, `LockService` and the acquire endpoint publish events via the shared `event_bus` (the acquire worker thread hands events over with `loop.call_soon_threadsafe`).

### `admin.py` — `/admin`

All endpoints require `require_admin()` (HTTP 403 for non-admins).

| Method | Path                                      | Description                                                 |
| ------ | ----------------------------------------- | ----------------------------------------------------------- |
| POST   | `/admin/locks/reset`                      | Clear all Redis locks; reset LOCKED devices to ONLINE.      |
| POST   | `/admin/devices/{device_id}/force-unlock` | Force-release one device's lock regardless of who holds it. |

## Error response format

All errors raised via the `AppError` hierarchy return JSON with two fields:

```json
{ "error": "lock_conflict", "detail": "Device 'scope-01' is locked by 'alice'" }
```

The `error` field is a snake_case slug; see `app/core/exceptions.py` for the full list.
